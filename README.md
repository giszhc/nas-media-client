# 云影 · 群晖 NAS 媒体中心

一个自托管的家庭影音客户端：连接群晖 NAS，自动扫描视频目录、识别剧集/电影分类、联网抓取封面与简介，
按优酷 Mac 客户端的版式在线播放。**同一套代码同时提供网页版、macOS 客户端与 Windows 客户端。**

## 一、功能一览

| 模块 | 说明 |
| --- | --- |
| 登录 | 输入 NAS 的 IP + 端口 + 账号密码，走群晖官方 File Station API（支持 HTTPS 自签名证书、两步验证） |
| 媒体库 | 递归扫描指定目录，自动识别 电视剧 / 电影 / 动漫 / 综艺 / 纪录片 / 短剧 / 音乐 |
| 命名解析 | 支持 `繁花.S01E03.2160p`、`庆余年 第二季 第08集`、`狂飙.EP12`、`[组名] 沙丘2.Dune.2024` 等常见命名 |
| 元数据 | 豆瓣（免 Key）自动匹配中文封面、简介、评分、类型、导演、演员；可选 TMDB 兜底 |
| 播放 | MP4/WebM 原画直连；MKV/AVI 等自动无损封装或实时转码（需 ffmpeg）；支持断点续播、选集、字幕 |
| 音乐 | MP3/M4A/FLAC/WAV/OGG 直连，APE/WMA/ALAC/DSD 实时转 MP3；专辑按曲目编号聚合，散装歌曲一首一条；读取目录里的 cover.jpg 当封面 |
| 音乐馆 | 独立的音乐页（`#/list/music`）：歌曲 / 歌手 / 专辑三栏，表格化歌单，支持按歌手、专辑筛选，按名称/歌手/专辑/时长/最近添加排序 |
| 音频播放器 | 独立的 `<audio>` 播放器与控件：大封面 + 歌名歌手 + 进度条 + 上一首/下一首 + 快退/快进 10 秒 + 倍速（1×/1.25×/1.5×/2×/0.75×）+ 音量 + 播放模式（列表循环/单曲循环/随机）+ 播放列表抽屉；收起后变底部迷你条继续放，支持系统媒体键（Media Session） |
| 在线歌词 | 进歌自动联网匹配歌词（网易云音乐为主、QQ 音乐兜底），滚动歌词逐句高亮居中，点某一句直接跳到该句；点封面或按 `L` 在封面/歌词间切换；没匹配上可手动搜「歌名 歌手」或重新匹配；匹配结果缓存 30 天（未命中缓存 24 小时） |
| 界面 | 首页 Hero 推荐位 + 横向海报流、分类页、详情页、全屏播放器、设置页 |
| 多端 | 浏览器直接访问（手机/平板/电视同一局域网可用）、macOS/Windows 桌面客户端 |

## 二、快速开始

### 0. 前置条件

- Node.js 18 或以上（`node -v` 检查）
- 群晖 DSM 6.x / 7.x，并已开启 **控制面板 → 文件服务 → 启用 File Station**
- 建议安装 ffmpeg（用于 MKV 等格式播放）：
  - macOS：`brew install ffmpeg`
  - Windows：下载 <https://www.gyan.dev/ffmpeg/builds/> 解压后，在「设置 → 播放与转码」里填入 `ffmpeg.exe` 路径

### 1. 启动

**方式 A：网页版（任意系统）**

```bash
cd nas-media-client
node server.js
# 浏览器打开 http://127.0.0.1:8787
```

启动后终端会打印局域网地址，例如 `http://192.168.2.12:8787`，手机/电视浏览器可直接打开。

**方式 B：macOS 客户端（推荐）**

项目根目录已有打好包的 `云影.app`，直接双击即可。它会自己拉起本地服务、打开独立窗口、关窗即退出，不经过浏览器。

客户端默认也监听 `0.0.0.0:8787`，也就是说**开着客户端的同时，手机/平板/电视照样能用浏览器访问** `http://<这台 Mac 的 IP>:8787`。只想本机用就 `HOST=127.0.0.1 open 云影.app`。

也可以双击 `启动云影-macOS.command`：优先启动 `云影.app`，只有客户端缺失或起不来时才退回 Chrome 应用窗口模式。

> 若系统提示「已阻止恶意软件并移到废纸篓」，是因为本地打包的 app 没有 Apple 开发者签名（macOS 26+ 对 arm64 的未签名应用直接判定为恶意）。执行一次即可修复：
> ```bash
> xattr -cr "云影.app" && codesign --force --deep --sign - "云影.app"
> ```

**方式 C：Windows 客户端**

双击 `启动云影-Windows.bat`。会后台启动服务，并优先用 Chrome、其次 Edge 的应用窗口打开。Windows 的 `云影.exe` 需要在 Windows 机器上执行 `npm run dist:win` 生成。

**方式 D：重新打包 / 改代码后重建**

```bash
cd desktop
npm install          # 首次
npm run dist:mac     # 打包 + 自动 ad-hoc 签名，产物在 desktop/dist/mac-arm64/云影.app
npm run dist:win     # 生成 exe 安装包 + 免安装版（需在 Windows 上跑）
```

打包后的客户端会自动内嵌并启动本地服务，用户无需安装 Node.js。数据目录在 `~/Library/Application Support/yunying-desktop/data`（与原 `data/` 结构一致，可直接拷贝迁移）。

### 2. 登录群晖

1. 打开应用 → 输入 NAS 地址（如 `192.168.1.100`）、端口（HTTPS 默认 `5001`，HTTP 为 `5000`）
2. 输入群晖账号密码；若开启了两步验证，勾选后填写 6 位动态码
3. 登录成功后会列出共享文件夹

> 该账号需要有 File Station 权限，否则只能看到部分目录。

### 3. 添加媒体目录

进入「设置 → 媒体目录 → 添加群晖目录」，选择例如 `/video/电视剧`、`/video/电影`。
可以添加多个目录，也可以给每个目录指定类型（默认「自动识别」）。

添加后自动开始扫描，首页会实时刷新进度。影片信息在后台逐条匹配，匹配完卡片自动出现封面。

## 三、媒体库组织建议

扫描器靠**文件名 + 目录名**判断类型与集数，推荐这样存放：

```
/video
├── 电视剧/
│   ├── 繁花 (2023)/
│   │   ├── 繁花.S01E01.2160p.WEB-DL.mkv
│   │   └── 繁花.S01E02.2160p.WEB-DL.mkv
│   └── 庆余年 第二季/
│       ├── 庆余年.第二季.第01集.mp4
│       └── 庆余年.第二季.第02集.mp4
├── 电影/
│   ├── 流浪地球2.2023.1080p.BluRay.mkv
│   └── 沙丘2.Dune.Part.Two.2024.BD1080P.mp4
├── 动漫/进击的巨人 最终季/01.mkv
└── 纪录片/蓝色星球.2001.BD1080p.mp4

/music
├── Beyond/海阔天空/          # 一个目录 = 一张专辑
│   ├── cover.jpg            # 有封面图就按专辑聚合
│   ├── 01 - 海阔天空.flac
│   └── 02 - 光辉岁月.mp3
└── 音乐/                     # 杂歌目录：一首歌一条
    ├── 华晨宇 - 寻.mp3
    └── 六哲 - 不苦的爱情.mp3
```

- 类型判定顺序：目录关键词（动漫 > 综艺 > 纪录片 > 短剧 > 电视剧 > 电影）→ 文件名是否含集数
- 同一目录下、片名和年份相同的文件会自动归为同一部剧的连续集
- 每部影片的文件夹里放 `poster.jpg` 可作为封面兜底（没有网络时也能显示）
- 音乐按目录形态自动分流：目录里文件带编号（`01 - 歌名`）或放了 `cover.jpg`/`folder.jpg` → 整张专辑一个条目，曲目按编号排；
  否则（文件名是「歌手 - 歌名」的大杂烩目录）→ 一首歌一个条目，卡片上直接显示歌名与歌手
- 专辑能被识别要满足「同一目录里 ≥3 首且 60% 带编号」或「目录里有封面图」。全是散装歌的目录不会凭空产生专辑，
  这些歌在音乐馆里统一归到「散装单曲」，仍然可以按歌手筛选、按专辑列排序

## 四、播放与转码

| 文件类型 | 播放方式 | 说明 |
| --- | --- | --- |
| MP4 / M4V / WebM（H.264/H.265/AAC） | 原画直连 | 支持拖动进度条，秒开 |
| MKV / TS / MOV（H.264 + AAC） | 无损封装 | 不重新编码，CPU 占用低，拖动进度会重新定位 |
| 其他编码（HEVC、VC-1、DTS 等） | 实时转码 | 转 H.264 + AAC，需要 ffmpeg |
| 无 ffmpeg | 仅原画直连 | MKV 等会提示安装 ffmpeg |
| MP3 / M4A / AAC / FLAC / WAV / OGG / Opus | 音频直连 | 独立音频播放器：大封面 + 曲名歌手 + 进度条 + 播放模式 + 播放列表抽屉，收起后底部迷你条继续播 |
| APE / WMA / ALAC / AIFF / DSD / WavPack | 实时转 MP3 | `libmp3lame` 192 kbps 立体声，需要 ffmpeg；转码流不支持拖动，进度条变只读 |

### 歌词是怎么来的

| 环节 | 做法 |
| --- | --- |
| 搜索 | `GET /api/lyrics?item=&ep=`，服务端拿曲目名 + 歌手 + 时长去搜；网易云结果少于 3 条时并入 QQ 音乐一起打分 |
| 打分 | 歌名精确 100 / 包含 78 / 长短相近 62 / 其余 20；歌手对得上 +45，对不上 −25；时长 ±3 秒 +18、>20 秒 −18；低于 62 一律不认 |
| 排序 | 歌手对得上的排前面（同名的原唱优先于翻唱，避免配到《后来(live)》这种） |
| 清洗 | 解析 LRC 的 `[offset:]`、一行多时间戳、去重；剥掉开头「作词 : 无 / 编曲：xxx / 美工：xxx」这类制作信息；有翻译歌词时合并成第二行 |
| 缓存 | `data/lyrics.json`：命中 30 天、未命中 24 小时（负缓存，避免每次播放都打网络）；解析规则改动会把 `CACHE_V` 加一，旧缓存自动作废 |
| 兜底 | 没匹配上时播放页显示「没找到歌词」，可手动搜「歌名 歌手」或点「重新匹配」强制刷新 |

### 画质档位（含 4K）

播放器右下角可切换清晰度，档位按源文件分辨率自动生成，不会超过源：

| 档位 | 分辨率 | 码率 | 编码器 |
| --- | --- | --- | --- |
| 原画 | 源文件原始分辨率 | 不重编 | — |
| 4K | 3840×2160 | 25 Mbps | `h264_videotoolbox`（macOS 硬编）/ `libx264` |
| 1080P | 1920×1080 | 8 Mbps | 同上 |
| 720P | 1280×720 | 4 Mbps | 同上 |

- macOS 上 4K 走 `h264_videotoolbox` 硬件编码，实测 10 秒 4K 片源转码耗时约 4.6 秒（快于实时），
  没有硬件编码器时自动退回 `libx264`（CPU 软编，4K 可能跟不上实时）。
- **H.265 片源**：浏览器内核解不了 HEVC 时会自动切到「4K H.264」档（同分辨率重编成 H.264），
  清晰度不降级；能硬解 HEVC 的浏览器（Safari、部分 Chrome）则直接原画播放。
- MKV 里的 HEVC 重封装时会补 `-tag:v hvc1`，否则浏览器会拒绝解码。

| 静音 | `M` |
| 全屏 / 退出全屏 | 双击画面、`F`、右下角按钮 |
| 画中画 | `P` |
| 下一集 | `N` |
| 关闭播放器 | `Esc` |
| 倍速 | 右下角「倍速」（0.5x ~ 2x） |

- 播放中 3 秒不动鼠标会自动隐藏控制层与光标，移动即唤回

- 同名字幕（`.srt` / `.vtt`）会自动加载

音频播放器是独立的一套控件，和上面视频播放页的快捷键互不影响。

| 操作 | 快捷方式 |
| --- | --- |
| 播放 / 暂停 | `空格`，或中央播放键 |
| 快退 / 快进 10 秒 | `←` / `→`，或播放键两侧的 ±10 秒按钮（会弹「快退 10 秒」提示） |

## 五、常见问题

**Q：登录提示「无法连接」？**
确认端口与协议：HTTPS 用 5001，HTTP 用 5000；若路由器做了端口映射，填映射后的端口。
自签名证书已在服务端放行，不会因证书报错。
点登录框下方的「扫描局域网，自动找到我的群晖」，会直接列出当前网段里所有群晖及其 IP，
点一下就填好了，比手输 IP 靠谱。

**Q：提示「无法访问该 IP / 系统未授予本地网络权限」？**
这是 macOS 15 起的「本地网络」隐私限制：任何非系统程序（含终端、Node、云影）第一次访问局域网
都要你手动授权，否则连 `ping` 都不通。
打开 **系统设置 → 隐私与安全性 → 本地网络**，把「终端」（以及列表里的「云影」「Node」）开关打开，
然后**完全退出并重启**云影。Windows 则在首次运行弹窗中勾选「专用网络」，或放行 Windows 防火墙。

**Q：忘记 NAS 的 IP 了？**
三个办法：① 登录页点「扫描局域网」；② 在群晖 **DSM → 控制面板 → 信息中心** 看 IP；
③ 路由器后台看已连接设备列表，主机名通常带 `DiskStation` / 你设置的设备名。
注意：`192.168.2.7` 和 `192.168.2.77` 是完全不同的两台设备，别漏掉最后一位。

**Q：能登录但看不到目录？**
该账号缺少 File Station 权限，或目录不在其可见范围内。用管理员账号在「控制面板 → 用户与群组 → 应用程序权限」中放行。

**Q：封面/简介一直是灰底？**
豆瓣接口偶发限流，等几分钟后在设置里点「立即重新扫描」，或在详情页点「重新匹配」手动指定条目。
网络环境访问不到豆瓣时，可在设置里填 TMDB API Key 作为兜底。

**Q：MKV 点了没反应？**
安装 ffmpeg 后重启服务；或在「设置 → 播放与转码」填写 ffmpeg 绝对路径。

**Q：歌没有歌词 / 歌词对不上？**
歌词是联网搜的（网易云 + QQ 音乐），需要这台机器能上外网。
- 冷门歌、翻唱、纯音乐（钢琴曲这种）搜不到很正常，播放页会显示「没找到歌词」。
- 对不上时点歌词面板右下角的「搜歌词」，手动输「歌名 歌手」再搜一次；
  或点「重新匹配」跳过 30 天缓存重新问一遍。
- 目录里放同名 `.lrc` 不走这套逻辑（目前只认联网歌词，本地 LRC 之后再加）。

**Q：4K 片源卡顿 / 提示「H.265 不支持」？**
说明当前浏览器内核没有 HEVC 解码能力（Chrome 在部分系统上不开放）。播放器会自动把 4K 片源
按原分辨率重编成 H.264（菜单里的「4K H.264」档），清晰度不降。若仍然卡，说明机器跟不上 4K 实时转码：
优先用 Safari 打开（原生支持 HEVC，可直接原画播 4K，几乎不吃 CPU），或在菜单里选 1080P。
Mac 上确认 ffmpeg 带 videotoolbox 编码器：`ffmpeg -encoders | grep videotoolbox`，
有 `h264_videotoolbox` 就说明硬编可用。

**Q：手机/电视怎么访问？**
同一局域网下打开启动日志里的局域网地址即可；建议在群晖或路由器上给这台电脑固定 IP。

**Q：密码存在哪里？**
存在 `data/config.json`（明文，仅本机可读）。不想保存就在登录时取消勾选「记住密码」。

**Q：端口被占用？**
`PORT=9000 node server.js` 换端口，或修改 `data/config.json` 里的 `port`。

```
├── server.js              本地服务：路由、登录、扫描、播放、转码

├── 云影.app               macOS 客户端（已打包 + ad-hoc 签名，双击即用）

├── 启动云影-macOS.command
└── 启动云影-Windows.bat
```

## 七、安全提示

- 服务默认监听 `0.0.0.0:8787`，局域网内任何设备都能访问。仅在可信网络中使用。
- 如需公网访问，请通过群晖反向代理 + HTTPS，并自行增加访问控制。
- `data/config.json` 内含 NAS 账号密码与登录 sid，请勿分享该目录。
